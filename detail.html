DETAIL PROYEK

Website Portofolio Pribadi

Website multi-halaman untuk memperkenalkan identitas, minat, dan contoh hasil pembelajaran di bidang teknologi informasi.

SR
HTML · CSS · Bootstrap 5 · JavaScript

Tujuan Proyek

Menerapkan materi Pemrograman Web dalam sebuah website statis yang responsif dan saling terhubung.

Fitur yang diterapkan

  • Navigasi untuk berpindah antarhalaman.
  • Layout responsif menggunakan grid dan komponen Bootstrap 5.
  • Halaman profil dan daftar proyek.
  • Halaman login dengan validasi form menggunakan JavaScript.

Proses pengerjaan

Proyek dimulai dengan menyusun struktur halaman HTML, dilanjutkan dengan menambahkan Bootstrap untuk tata letak, CSS untuk identitas visual, dan JavaScript untuk memvalidasi input pada form login. Setiap tautan diperiksa agar mengarah ke halaman yang sesuai.

Bagian ini adalah contoh penjelasan. Ubah sesuai proses dan fitur yang benar-benar kamu pahami serta implementasikan.
